# Smart Buy Hub

Live site: [https://smart-buy-hub.web.app/](https://smart-buy-hub.web.app/)

A curated affiliate shopping site that hand-picks the best deals on fashion, beauty, accessories, and home decor from trusted Indian retailers, paired with in-depth buying guides. Built with React, React Router, and Firebase, and deployed on Firebase Hosting.

## Features

- Curated product listings across clothes, shoes, beauty, accessories, and home decor
- Product search and category browsing
- Buying guides / blog with individual post pages
- About, contact, and privacy policy pages

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
firebase deploy
```
